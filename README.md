# Lumina – אב-טיפוס

כלי ליהלומן שיושב מול לקוח: מעצבים טבעת, הלקוח מאשר תמונת AI, והמערכת מפיקה קובץ STL ליציקה בשעווה ודף מפרט (מידות, משקל זהב משוער, עלות).

## הזרימה
1. בחירות בממשק → פרומפט → תמונה ללקוח (עם אבן).
2. הלקוח מאשר → עריכת תמונה שמסירה את כל האבנים (`app/catalog.py: STONELESS_EDIT`).
3. התמונה בלי אבן → TRELLIS.2 (PiAPI) → GLB.
4. `app/ring/postprocess.py`: הפיכה לגוף סגור, סקאלה לפי מידת האצבע, בדיקת עובי, נפח ומשקל → `ring.stl` + `ring_view.glb`.
5. כרטיס עבודה בעברית: `/designs/<id>/spec`.
6. מחיר: היהלומן קובע אותו (או משתמש במחיר המחושב). הלקוח לא רואה מחיר עד שהיהלומן לוחץ "שליחת הצעת המחיר".
7. אישור הלקוח: בחנות (חתימה על המסך) או בקישור אישי `/o/<token>`. בקישור, האישור נפתח רק אחרי שנשלח מחיר. האישור נשמר עם שם, חתימה, תאריך והמחיר שנשלח, ומפעיל את הכנת הקובץ אם עוד לא הוכן.

כל שלב (הדמיה, הסרת אבן, תלת-ממד, STL) מוצג באחוזים. ההערכה מבוססת על זמני הריצות הקודמות (`data/timings.json`).

מסכים: סטודיו (עיצוב → מחיר וקובץ → אישור), הזמנות (לפי שלב), הגדרות (עסק ולוגו, שיתוף עם הלקוח, תמחור עם רווח, ייצור).

## הרצה
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # למלא מפתחות; בלי מפתחות הכל רץ במצב mock
.venv/bin/uvicorn app.main:app --port 8000
```
ואז לפתוח http://localhost:8000

במצב mock התמונות הן ציור דמה, והתלת-ממד הוא הדגימה ב-`samples/`. זה מאפשר לבדוק את כל הזרימה בלי עלות.
כדי לראות את מסכי ההתקדמות במצב mock: `MOCK_DELAY=6 .venv/bin/uvicorn app.main:app --port 8000` (כל שלב מחכה 6 שניות).

הספריות בצד הלקוח (GSAP, Lenis, model-viewer) נמצאות ב-`web/vendor`, כך שהאתר לא תלוי ב-CDN.

## תצוגת היהלומים
בבחירת צורת האבן מוצג יהלום תלת-ממדי מסתובב: על הצורה שמעליה עומד העכבר, ובטאבלט על הצורה שנבחרה. המודלים סכמטיים ונוצרים בקוד: `.venv/bin/python scripts/make_gems.py` (כותב ל-`web/gems`). הגדלים במ"מ הם הערכה לפי אבן של קראט אחד, ומשתנים לפי שורש שלישי של המשקל.

### תמונות לשיבוץ, לחישוק ולצורות
תמונות פוטוריאליסטיות נוצרות פעם אחת ונשמרות בתיקייה `web/catalog` (עולות כמה דולרים בסך הכול, ולא בכל שימוש):
```bash
.venv/bin/python scripts/make_catalog_images.py --dry-run      # רק מציג את הפרומפטים
.venv/bin/python scripts/make_catalog_images.py --only shape   # קודם קטגוריה אחת, לבדוק את המראה
.venv/bin/python scripts/make_catalog_images.py                # כל מה שחסר
```
בלי תמונות: הצורות מציגות את המודל התלת-ממדי, והשיבוץ והחישוק מציגים תיאור בלבד. להחלפת תמונה: `--ids round --force`.

## סיסמה
ב-`.env`: `STUDIO_PASSWORD=...`. הסטודיו, ההזמנות, ההגדרות וכל ה-API דורשים כניסה. קישורי הלקוח (`/o/...`) נשארים פתוחים. בלי סיסמה האתר פתוח לכל מי שמגיע לכתובת, ולכן חובה להגדיר אותה לפני שחושפים אותו לאינטרנט. שינוי הסיסמה מנתק את כולם. זה פתרון זמני עד שיהיו חשבונות.

## עיבוד קובץ ידני
```bash
.venv/bin/python -m app.ring.postprocess path/to/ring.glb --inner-diameter 17.19 --out out/
```

## הנחות פתוחות (לאמת מול יהלומן)
- מידה ישראלית = היקף פנימי במ"מ (54 → קוטר 17.19 מ"מ). ניתן לשנות בהגדרות.
- צפיפויות הסגסוגות ב-`app/ring/postprocess.py: DENSITIES` מקורבות.
- מקדם התכווצות השעווה: ברירת מחדל 1 (ללא).
- הפורמט המדויק של base64 ב-PiAPI לא מתועד: `PIAPI_IMAGE_FORMAT=datauri|raw`.

## עדיין אין
הרשמה וסיסמה לממשק היהלומן, ריבוי יהלומנים, תשלומים וקרדיטים, אחסון בענן. הנתונים נשמרים בתיקייה `data/`.
קישורי הלקוח עובדים רק כשהאתר מפורסם בכתובת ציבורית (בהגדרות: "כתובת האתר הציבורית").
